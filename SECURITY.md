# Security Policy

## Official channels
The official channels of this project are, exhaustively: GitHub Issues
(bug reports and corrections), GitHub Discussions (methodology questions),
and email <pengyins@illinois.edu> (private contact with the maintainer,
including security and impersonation reports). Any other account, package,
or channel claiming to represent this project is not official.

## Reporting a vulnerability
Report privately by email. Acknowledgment within 7 days; triage and an
initial assessment within 30 days; coordinated disclosure timing agreed
with the reporter. In scope: the tooling in this repository. Out of scope:
the panel projects studied by the research (report those to their own
security channels).

## Reporting impersonation
Report lookalike repositories, packages, or accounts by email, and escalate
to the hosting platform's abuse process.

## Account security
The maintainer account controlling this repository has multi-factor
authentication enabled. This is a solo-maintainer project; see the
supply-side companion repository's GOVERNANCE.md pattern for the documented
mitigations this project follows.
